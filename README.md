# MG3
## Devlog
1. default value for floats and ints are 0, for bools are false(empty checkbox) and for strings are null(blank text field).
2. Update method is called in every frame.
3. In the TimerText class, _gameTimer is a reference to Timer, and inside Update method, we check if IsFinished method from Timer is true in every frame. If it's ture, gameover, if not keep checking.
